# Public Release Notes

This file is the single source of truth for public-facing changelogs and update announcements of KUA Kecamatan Ngoro website.

---

## [v2.0.0] - 2026-11-24
- status: released
- visibility: public

### Introduction
Selamat datang di KUA Ngoro 2.0! Pembaruan besar ini menghadirkan peningkatan performa web menyeluruh, keandalan jadwal sholat offline bagi warga Kecamatan Ngoro, antarmuka dialog yang lebih aksesibel dan ramah pembaca layar, serta sistem pengumuman publik transparan.

### Summary
Pembaruan komprehensif pada performa render animasi, jadwal sholat hisab Kemenag mandiri secara offline, dialog pop-up native berstandar aksesibilitas tinggi, serta halaman publik pengumuman pembaruan.

### NEW
- Halaman Publik Catatan Rilis (/updates) untuk transparansi perkembangan layanan digital KUA Kecamatan Ngoro.
- Banner pop-up pengumuman pembaruan versi baru otomatis yang ramah pengguna dan dapat dinonaktifkan.
- Kalkulasi hisab astronomis jadwal sholat offline berstandar Kemenag RI khusus koordinat Kecamatan Ngoro, Kabupaten Jombang.

### IMPROVED
- Migrasi engine animasi ke Motion modern untuk performa render lebih mulus, konsumsi memori lebih hemat, dan penghormatan penuh terhadap preferensi Reduce Motion.
- Dialog interaktif publik dan konfirmasi aksi kini menggunakan elemen native HTML `<dialog>` dengan pengembalian fokus otomatis dan navigasi keyboard yang aman.
- Keandalan strip Dynamic Island jadwal sholat harian kini terlindungi dari gangguan koneksi API pihak ketiga.

### FIXED
- Perbaikan sinkronisasi penutupan jendela dialog pada penekanan tombol Escape dan klik area latar belakang.
- Penanganan timeout dan kegagalan respons data jadwal sholat saat jaringan internet tidak stabil.

### CONTENT
- Penambahan dokumentasi panduan fitur pembaruan dan transparansi sistem digitalisasi KUA Ngoro.
- Pembaruan informasi akurasi waktu jadwal sholat hisab Kemenag untuk wilayah Ngoro dan sekitarnya.

## [v1.0.0] - 2026-10-24
- status: released
- visibility: public

### Introduction
Peluncuran perdana situs resmi Kantor Urusan Agama (KUA) Kecamatan Ngoro, Kabupaten Jombang, Jawa Timur.

### Summary
Portal informasi publik resmi KUA Ngoro untuk mempermudah akses layanan nikah, wakaf, kemasjidan, dan bimbingan keagamaan bagi masyarakat.

### NEW
- Portal resmi layanan nikah dengan checklist berkas interaktif N1-N7 dan transparansi biaya resmi Kemenag.
- Fitur jadwal sholat harian terintegrasi dengan zona waktu WIB (Asia/Jakarta).
- Galeri dokumentasi kegiatan kepenghuluan, pembinaan calon pengantin, dan penyuluhan agama.
- Pusat informasi berita dan pengumuman resmi keagamaan Kecamatan Ngoro.
